Enhancing User Experience of an e-Commerce SaaS Dashboard

Enhancing User Experience of an e-Commerce SaaS Dashboard

VIEW PROJECT

Overview

Dwt eCommerce SaaS offers a comprehensive platform for e-commerce businesses to manage their online stores, track sales, add products, generate reports, and analyze performance seamlessly. In a bid to enhance the dashboard’s usability, feedbacks from the users were gathered and synthesized, also some Insights from the previous user qualitative research that was done indicated critical areas that need improvement.

This project aims to improve the user experience of the existing dashboard. The primary objective is to enhance the dashboard’s usability and create a more intuitive, efficient, and user-friendly dashboard that enables eCommerce businesses to manage their online store operations effectively and efficiently.

After discussing the major problems identified through the insights gathered from the research data, and setting priorities with the stakeholders to ensure we tackle the most impactful opportunities for this piece of work, these defined problems were to be addressed.

  • Poor Navigation
  • Mobile Adaptiveness.
  • Introducing Multiple Sites functionality
  • Data visualization
  • Cluttered and confusing interface
  • Ineffective Notifications

 

The Solution Summary

 

Optimizing the User Flow & Navigation menu

 

Introducing the Mobile app MVP

The plan is to introduce the “Create order” features to the mobile version in the next iteration, this is currently available on the web app only, it’s out of scope for this piece of work.

Introducing Dark Mode Version

 

Order Preview Features

The order preview feature is one of the major features added after the first round of usability testing of the new solution. This feature allows users to preview order details with less friction quickly, users would be able to preview orders to see the essential information without having to change the order’s read/seen status, which was the only way to see order details in the previous design.

 

Highlighting the New Features

Introduced a subtle in-app onboarding to create awareness of newly added features to users.

 

Key Takeaways

Using a user-centered design approach, I was able to design a solution that successfully enhanced the product’s user experience. The new design simplifies navigation, offers clear data visualizations, streamlines user flow, and is mobile-friendly. The improved experience will empower eCommerce businesses to manage their online store operations more effectively and efficiently.

Even though there is still more work to be done in the next iteration when the metrics start coming in, I’m quite proud of the work done so far and I’m looking forward to its great impact on the business goals and the fact that the solution addresses some key user needs.

Designing For Growth: Real Estate Investment Platform Redesign

Seamless Shopping Experience: Improving User Experience Across DwtStore’s Web and Mobile Platforms

Seamless Shopping Experience: Improving User Experience Across DwtStore’s Web and Mobile Platforms

VIEW PROJECT

About

Dwt Store is an eCommerce company that specializes in providing convenient online shopping for Men and Women in Nigeria.

The Goal

To create an improved shopping experience for users on Dwtstore website (Both web & mobile), to increase conversion rate, so as to meet business revenue goals. 

About my role

  • Product Designer

 

Problem Summary

To get an overview of the problem, I started with the store performance analytics data to see how users interact with the website, where they are successful, struggle, and fail. I made use of the website’s quantitative data to identify problems and opportunities areas of critical pages of the website which gives scoped user problems to address in various areas of the website, some of these areas include the cart page and checkout page, having confusing process leading to poor conversion rate. Qualitative research was done via Zoom for the user testing to get more insights, leading to the iterated solution. Other issues that were found include; critical accessibility issues in areas like product pages, broken mobile responsiveness, website loading time, lack of personalized recommendations, and poor search functionality.

Solution Summary

Analytics showed that 87% of the users access the website from their mobile devices, so it was crucial to prioritize mobile responsiveness while ensuring consistency and cohesion with the web design to ensure a seamless user experience across all devices. The solution also includes improving the accessibility by making changes to some colors to ensure optimal contrast. Added “order via WhatsApp” features, improved search functionality, and simplified check-out process.

Key Result

A solution that improved the metrics and KPI (like customer retention, bounce rate, cart abandon rate, initiate_checkout to successful Purchase rate) which led to a sales conversion rate drastically increased by approximately 158%. And not only that but also a significant reduction in the email and WhatsApp support resources due to an improved experience for the users.
